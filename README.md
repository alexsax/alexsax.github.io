# alexsax.github.io

Source for the personal academic website of Alexander Sax (Sasha) — https://alexsax.github.io/

Plain HTML/CSS, no build step; GitHub Pages serves `main`. Layout adapted from
[Jon Barron's template](https://github.com/jonbarron/jonbarron_website).

- `index.html` — page content, Open Graph tags, and the schema.org `Person` JSON-LD (keep `sameAs` / affiliation in sync with reality)
- `images/alexander-sax.jpg` — canonical headshot URL used by `og:image` and structured data (drop a higher-resolution file in under the same name any time)
- `data/Sax-CV.pdf` — built from the `cv-latex` repo
